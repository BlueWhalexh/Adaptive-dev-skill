# Example Requests

Use these as copyable starting points.

## Tiny

```text
Use $adaptive-dev-workflow.
Fix the typo in README.md. Keep the change limited to that sentence and verify the markdown still renders as plain text.
```

## Small

```text
Use $adaptive-dev-workflow.
Fix the bug where the Save button stays disabled after editing the title. Keep the change scoped to the form state logic and run the relevant component test.
```

## Medium

```text
Use $adaptive-dev-workflow.
Add a status filter to the issues page. Reuse existing filter patterns if present. Stop before changing the backend API. Verify active filter, reset, and empty state behavior.
```

## Large

```text
Use $adaptive-dev-workflow.
Refactor token refresh handling across the API client. Preserve existing session semantics, add regression coverage, and pause if any public API or security behavior needs to change.
```

## Debugging

```text
Use $adaptive-dev-workflow.
Investigate why the checkout test is flaky. Reproduce the failure first, identify the cause, then make the smallest fix and verify with repeated runs.
```
