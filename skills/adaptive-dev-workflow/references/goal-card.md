# Goal Card

仅用于跨会话或长时间目标。保持一页，不记录每个 Task、命令或 Review 往返。

```markdown
# Goal: <name>

## Current outcome
<用户当前真正要看到的结果>

## Mode
prove | improve | harden

## Basic Usable
- <代表场景或真实链路>
- <关键失败边界>

## Top blocker
<当前唯一最高价值问题>

## Latest evidence
- <真实结果、矩阵或复现>

## Next action
<下一步唯一动作>

## Deferred
- <不阻塞当前目标的问题>

## Decisions
- <用户已经做出的稳定取舍>
```

更新规则：只有 Current outcome、Mode、Top blocker、Latest evidence、Next action 或稳定决策变化时更新。不要将 Goal Card 变成 Plan、日志或 workflow state machine。
